# VOX ROYALE — Original visual asset seed pack

These are newly authored scalable vector assets for the native Android experience. They are inspired by broad social voice-room conventions (ornate avatar frames, premium badges, gift objects, coin currency and atmospheric room backdrops), not copied from Yalla source files or logos.

## Included
- vox_room_background.svg — premium dark room stage backdrop
- vox_gold_avatar_frame.svg — gold avatar frame overlay
- vox_gift_rose.svg — rose gift illustration
- vox_gift_crown.svg — crown gift illustration
- vox_vip_badge.svg — VIP badge illustration
- vox_coin.svg — in-app coin illustration

## Integration note
SVG files are kept as source artwork. Android's standard drawable pipeline may require conversion to VectorDrawable XML or raster PNG/WebP before runtime use. Do not treat this seed pack as the requested full 1,400-asset library; it is the first original asset batch.
